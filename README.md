# Timer

**[timer.jotaen.net](https://timer.jotaen.net)**

A programmable timer web app, e.g. for gym workouts or stretching sessions.

Timer programs are specified in a simple text format. The app is serverless. Timer programs are stored in the URL. They can be shared or transferred either via URL or QR code.

Try a demo timer: https://timer.jotaen.net/#demo
